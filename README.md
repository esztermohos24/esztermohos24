### Featured Project

#### 🏀 Basketball Team Management Application (BSc Thesis)
* **Overview:** A cross-platform team management application designed for basketball coaches and players to organize team operations and analyze match performance.
* **Tech Stack:** `Flutter`, `Dart`, `C#`, `.NET`, `TCP / TLS`
* **Key Features:**
  * Custom TCP communication layer secured with TLS between the mobile client and C# backend.
  * Team roster management, training attendance tracking, and shared event calendars.
  * Live/post-game player statistics logging, training plans, and photo-based tactical playbooks.
